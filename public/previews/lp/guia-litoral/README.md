# Guia Imobiliário Litoral

Landing page institucional estática apresentando a base de inteligência do Litoral Norte do RS (mercado, captação de corretores, direito imobiliário e fundamentos).

Servida via Nginx a partir de um único `index.html`, sem backend ou funcionalidades dinâmicas.

Deploy: EasyPanel, projeto `web-sites`, domínio `guia.jpstudio.tech`.
